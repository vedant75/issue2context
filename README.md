# Issue2Context

Issue2Context is a research and learning project investigating repository
context retrieval for coding agents.

## Problem

Given a natural-language GitHub issue and a frozen repository snapshot,
retrieve and rank the code context most useful for diagnosing and resolving
the issue under a limited context budget.

## Initial questions

- How do lexical, dense, and hybrid retrieval differ on real software issues?
- How much useful code context can we recover under fixed token budgets?
- Which kinds of repository queries cause different retrieval methods to fail?
- Can a retrieval system recognize when the repository does not contain
  enough evidence?

## Status
